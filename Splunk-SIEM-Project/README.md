Splunk SIEM Security Monitoring Project
Project Overview
This project involved using Splunk Enterprise to practise Security Information and Event Management (SIEM) activities.
The aim was to upload and analyse sample security logs, investigate failed and successful login attempts, identify source IP addresses, examine account lockout events, and create a security monitoring dashboard.
Tools Used
Splunk Enterprise 10.6.1.1
Windows 11
Search Processing Language (SPL)
Skills Practised
Security monitoring
Log analysis
SIEM operations
Failed login investigation
Source IP investigation
Dashboard creation
Basic incident investigation
Project Environment
The project used five fictional security events created for learning purposes. The events did not represent real user activity or an actual security incident.
Evidence
Screenshots and a project report are included to demonstrate the practical activities completed.
